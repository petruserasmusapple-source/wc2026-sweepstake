Connect a Google Sheet as the score database. You update scores in the sheet — everyone sees them live on this site.

Step 1 — Set up the Google Sheet

1
Open your WC2026 Sweepstake Scores Google Sheet
2

3
Click the + at the bottom to add a second tab — name it exactly Draw
4
Draw tab — headers in row 1: participant   hat1   hat2 — then paste the draw results from the Draw tab on this site after running the draw

Step 2 — Publish Both Tabs

1
In Google Sheets click File → Share → Publish to web
2
First: select Sheet1 → CSV → Publish → copy the URL → paste in Scores URL below

Second: select Draw → CSV → Publish → copy the URL → paste in Draw URL below
